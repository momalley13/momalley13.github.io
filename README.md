# Refrigerant PT

Saturation pressure–temperature lookup for 194 refrigerants used in domestic, commercial, industrial, air-conditioning, automotive, chiller, ultra-low, transport, and legacy systems.

Training values. Confirm the OEM chart before you set a control or open a system.

Live app: [https://momalley13.github.io/](https://momalley13.github.io/)

## On an iPhone

1. Open [https://momalley13.github.io/](https://momalley13.github.io/) in Safari.
2. Tap the Share button.
3. Tap **Add to Home Screen**.
4. Tap **Add**.

The icon opens full screen and works offline after the first load.

Project record, source, and the decisions behind the chart: [momalley13/refrigerant-pt](https://github.com/momalley13/refrigerant-pt).
